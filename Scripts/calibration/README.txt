BGMI CALIBRATION SAMPLES FOLDER
===============================

Place cropped PNG reference samples from real BGMI gameplay recordings here
(e.g., weapon icons, skull/headshot badges, knock icons, or kill-feed strips).

Recommended:
Use the built-in Calibration Tool in the GUI ("Calibrate: Capture BGMI Kill-Feed Sample")
or run:
    python Scripts/main.py --calibrate --video path/to/bgmi_gameplay.mp4

This folder intentionally ships empty so that no fake or non-BGMI templates are used.
